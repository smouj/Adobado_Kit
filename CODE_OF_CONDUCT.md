# Código de conducta

Este proyecto busca un espacio respetuoso y directo.

- Crítica técnica, sin ataques personales.
- Nada de discriminación, acoso ni lenguaje hostil.
- Respeta las licencias y el trabajo de terceros.
- Los desacuerdos se resuelven con argumentos y pruebas, no con ruido.

Los mantenedores pueden cerrar issues o PRs que incumplan estas reglas.
