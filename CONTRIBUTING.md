# Contribuir

Gracias por querer mejorar Adobado Kit.

## Principios

- Nada de nube obligatoria, cuentas ni telemetría.
- Nada de dependencias opacas: si añades una librería, incluye su licencia.
- Cada app debe abrir, editar y exportar sin conexión.

## Flujo

1. Abre un issue describiendo el problema o la propuesta.
2. Haz cambios pequeños y enfocados.
3. Prueba el flujo completo en local (abrir → editar → exportar).
4. Actualiza la documentación y, si cambia la interfaz, una captura.
5. Envía el PR con una descripción clara y el alcance.

## Estilo

- HTML, CSS y JavaScript sin frameworks cuando sea posible.
- Español para la interfaz y la documentación; inglés para nombres técnicos.
- Respeta la marca y no imites la identidad visual de Adobe.
